# 激波–界面不稳定性术语词典

**Shock–Interface Glossary** — 面向 RMI / RTI / ICF / 激波反射 / 湍流混合方向的中英术语词典。

| 词条 | 启用（active） | 置信度 | 搭配句 |
|---|---|---|---|
| 3543 | 2692 | 高 2401 / 中 120 / 低 171 | 4685 |

## 为什么做这个

机器翻译在通用文本上已经够用，但在激波–界面不稳定性这类方向上会**系统性地**译错术语：

- `Richtmyer–Meshkov instability` 被音译成“里奇迈尔-梅什科夫不稳定性”，而中文文献里普遍直接写 **RM 不稳定性**；
- `Atwood number` 与 `Atwood ratio` 被混成同一个词；
- `reshock`、`freeze-out`、`spike/bubble`、`baroclinic vorticity` 这些词，通用词典要么没有，要么给的译法在本领域是错的；
- 同一个英文概念在不同子领域译法不同（`interface` = 界面/交界面，`mixing` = 混合/掺混）。

人工整理当然可以解决，但不可扩展：几百篇 PDF 里的术语，靠人一条条查对，成本极高。这个项目想验证一件事——**能不能用大模型把“术语对齐”做成可机械验证的流水线**，而不是让模型自由翻译。

## 怎么做的

核心原则：**模型只做“指认”，不做“创作”；每条中文必须能在给定译文里逐字找到。**

1. **语料**
   - 个人 Zotero 文库的全文缓存（约 1.4 万页）；
   - 四组中英对照教材（OCR 后约 2500 页）：Tennekes《湍流初级教程》、Drake《高能量密度物理》、Ben-Dor《激波反射现象》、Landau《流体动力学》；
   - arXiv 最新摘要 200 余条。
2. **候选术语**
   - 优先取教材书末索引（规范术语 + 页码）；
   - 无索引时用跨文献 n-gram 频次（本地脚本，不耗 token）。
3. **抽取式对齐（关键一步）**
   - 按章节号把英文原文与中文译本切块；
   - 把英文候选和对应中文段落一起给模型，要求**从中文段落里逐字摘出**对应写法，摘不出就写“未定”；
   - 拿到结果后做字符串校验：不是原文连续子串的一律丢弃。
   - 这样模型没有“自由翻译”的空间，幻觉会被机械地筛掉。
4. **多判与证据**
   - 每条术语至少两遍独立判定；
   - 对中置信条目再做“五证据复核”：从不同文献取 5 条原句，`confirm` 升级、`correct` 改译、`unsure` 降级。
5. **人工裁定（少量但关键）**
   - `Richtmyer–Meshkov` 保留英文，中文写「RM 不稳定性」；
   - `Atwood number` = 阿特伍德数，`Atwood ratio` = 阿特伍德比；
   - `reshock` = 反射激波（备选“二次激波”）。
6. **置信度分级**
   - 高：逐字校验通过或多判一致；
   - 中：模型判定但证据较弱；
   - 低/未定：保留英文，不强行给译名。

## 数据文件

| 文件 | 说明 |
|---|---|
| `data/terms.tsv` | 词典本体，16 列：英文、主译、备选、词性、领域、定义、搭配、易错点、来源、置信度、状态等 |
| `data/collocations.tsv` | 每词最多 3 条真实句式（来自语料原句） |
| `data/conflicts.tsv` | 仍存疑的条目（默认策略：保留英文） |

## 用法

作为 DSH skill 使用（放到 `~/.dsh/skills/shock-interface-glossary/`）：

```bash
# 查词
python scripts/lookup.py --text 论文摘要.md

# 生成带术语表的翻译提示词
python scripts/translate_prompt.py --text 论文摘要.md --out prompt.md

# 增词/改词
python scripts/add.py --en "reshock" --zh "反射激波" --alt "二次激波" --confidence 高
```

也可以脱离 DSH 使用：`terms.tsv` 就是一张普通表，直接喂给任何翻译流程。

## 局限

- 术语对应来自公开论文与教材的用法，**不包含原文**，不替代原文献；
- 教材类条目里可能有 OCR 造成的错字，已按置信度标注；
- 低置信与未定条目建议保留英文，不要盲信；
- 不同期刊/作者用词存在差异，词典给的是“主流写法”，不是唯一写法。
